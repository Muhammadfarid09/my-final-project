## 1. ปรับแต่งความละเอียดของหน้าแรกบนมือถือ (index.php) ให้สมบูรณ์แบบตามหลัก HCI (Black & Gold Theme)

* **ผลการพัฒนา / การแก้ไข (สำหรับนำไปใส่บทที่ 4):**
  * **แก้ไขปุ่มซ้ำซ้อนบนแถบ Navbar ด้านบนบนจอมือถือ (Redundant Navigation Elimination):**

    * สำหรับสมาชิกที่เข้าสู่ระบบแล้ว: ทำการซ่อนปุ่ม Hamburger Menu (`.navbar-toggle`) เพื่อไม่ให้ซ้ำซ้อนกับแถบ Mobile Bottom Navigation Bar และแทนที่ด้วย **Mobile Mini Profile Pill** (`.mobile-top-user-pill`) ดีไซน์หรูหรา แสดงรูปอวาตาร์, ชื่อสมาชิกย่อ และ Badge ระดับสมาชิก (Tier) ที่แตะแล้วเปิดหน้า [`profile.php`](file:///c:/xampp/htdocs/ts-pattani/profile.php) ได้ทันที
    * สำหรับผู้ใช้ทั่วไป (Guest): ยังคงแสดงปุ่ม Hamburger Menu ตามเดิม เพื่อให้สามารถเปิดลิ้นชักเมนูและกดเข้าสู่ระบบ/สมัครสมาชิกได้อย่างสะดวก
  * **ปรับแต่งระยะเลื่อนป้องกันการบดบังเนื้อหา (Scroll Clearance & Offset 84px):**

    * เพิ่มระยะบัฟเฟอร์ความปลอดภัย 22px เหนือแถบ Bottom Nav (ความสูง 62px) ทำให้การ์ดและเนื้อหาท้ายสุดของหน้าเว็บเลื่อนพ้นขอบบนของแถบนำทางอย่างสมบูรณ์แบบบนสมาร์ตโฟนทุกรุ่น
  * **ปรับแต่ง Typography ของ Hero Heading บนจอมือถือให้อ่านสบายตาและตัดคำสวยงาม:**
    * ใน [`index.php`](file:///c:/xampp/htdocs/ts-pattani/index.php) เพิ่มคลาส `hero-br-desktop` ให้กับแท็ก `<br>` เพื่อยกเลิกการตัดบรรทัดแบบตายตัวบนหน้าจอมือถือ
    * ใน [`assets/css/responsive-mobile.css`](file:///c:/xampp/htdocs/ts-pattani/assets/css/responsive-mobile.css) ปรับขนาดหัวข้อ `.hero-dark-title` บนหน้าจอกว้าง &le; 768px เป็น `font-size: 26px; line-height: 1.4;` และบนหน้าจอ &le; 480px เป็น `font-size: 23px; line-height: 1.42;` พร้อมกำหนด `overflow-wrap: break-word;`
    * ช่วยให้จังหวะการอ่านและสระ/วรรณยุกต์ภาษาไทยไม่ชนกัน ข้อความ "ยกระดับทุกการแข่งขัน สัมผัสประสบการณ์ สนามแบดมินตันระดับพรีเมียม" แสดงผลได้สมดุลสวยงาม
  * **เสริมปุ่มออกจากระบบ (Logout CTA) ในหน้าโปรไฟล์:**

## 2. ปรับปรุงแถบสรุปการจองและแก้ไขปุ่มไปยังหน้าถัดไปบนมือถือ (booking.php)

* **ผลการพัฒนา / การแก้ไข (สำหรับนำไปใส่บทที่ 4):**
  * **แก้ไขปัญหาปุ่มถัดไปในขั้นตอนที่ 3 โดนแถบเมนูล่างซ้อนทับ (Mobile Fixed Collision Resolution):**
    * ปรับตำแหน่งการตรึงของ `.sticky-summary-bar` ให้ลอยตัวอยู่เหนือแถบเมนูนำทาง (`.mobile-bottom-nav`) ด้วย `bottom: calc(62px + env(safe-area-inset-bottom, 0px)) !important;` เมื่อผู้ใช้เข้าสู่ระบบ
    * รองรับสถานะผู้ใช้ทั่วไป (Guest) โดยคงตำแหน่งไว้ที่ `bottom: 0;` อย่างถูกต้อง
    * กำหนด `z-index: 999;` ลอยตัวเหนือเนื้อหาหน้าเว็บอย่างสมบูรณ์โดยไม่ทับซ้อนกับ Modal ยืนยันต่างๆ
  * **ออกแบบ Mobile Booking Dock เป็นแบบ 2 ฝั่ง ซ้าย-ขวา (Modern Compact Split Dock):**
    * ปรับเปลี่ยนจากเดิมที่เรียง 3 แถวแนวตั้ง (กินพื้นที่เกือบ 130px) มาเป็นแถวแนวนอน 2 ฝั่ง (ความสูงเพียง ~58px):
      * **ฝั่งซ้าย (Summary Metrics):** แสดงยอดเงินรวม `.sticky-metric-total` ตัวเลขสีทองเด่นชัดขนาด 16px และมีแถวย่อยแสดงจำนวนชั่วโมงกับชื่อสนามขนาดกะทัดรัด 11px
      * **ฝั่งขวา (Primary Action CTA):** วางปุ่ม `.btn-sticky-next` ("ต่อไป: บริการเสริม") เด่นชัดที่มุมขวาล่าง ความสูง 44px ตามมาตรฐาน HCI Touch Target
    * สถานะของปุ่มชัดเจน 100%: แม้ยังไม่ได้เลือกสนาม (`disabled`) ปุ่มก็ยังคงปรากฏชัดเจนพร้อมขอบและข้อความอ่านออก ทำให้ผู้ใช้ทราบทันทีว่าปุ่มถัดไปอยู่ที่ใด และเมื่อคลิกเลือกสนาม ปุ่มจะสว่างเป็นสีทองอร่ามทันที
  * **ปรับระยะเลื่อนในขั้นตอนที่ 3 (`#stepPanel3`):**
    * เพิ่ม `padding-bottom: calc(140px + env(safe-area-inset-bottom, 0px)) !important;` ใน `#stepPanel3` เพื่อให้ผู้ใช้สามารถเลื่อนดูคอร์ทสุดท้าย (คอร์ท 10) และปุ่มเปลี่ยนเวลาเริ่มต้นได้พ้นแนวแถบตรึงด้านล่างทั้งหมด
  * **ปรับโครงสร้างโค้ดตามหลัก DRY และ Separation of Concerns:**
    * จัดกลุ่มสไตล์ของ Booking Wizard ทั้งหมดให้อยู่ใน [`assets/css/booking-wizard.css`](file:///c:/xampp/htdocs/ts-pattani/assets/css/booking-wizard.css) และตัดสไตล์ที่ขัดแย้งออกจาก [`assets/css/responsive-mobile.css`](file:///c:/xampp/htdocs/ts-pattani/assets/css/responsive-mobile.css)

* **ปัญหาที่พบและวิธีแก้ (สำหรับนำไปใส่บทที่ 5):**
  * *ปัญหาเดิม:* ในหน้าจองสนามขั้นตอนที่ 3 บนมือถือ ผู้ใช้ไม่สามารถมองเห็นหรือกดปุ่ม "ต่อไป: บริการเสริม" ได้ เนื่องจากแถบ `.sticky-summary-bar` และ `.mobile-bottom-nav` ถูกตรึงอยู่ที่ `bottom: 0` ทั้งคู่ และ Bottom Nav มี `z-index: 1000` สูงกว่า จึงทับปุ่มถัดไปที่อยู่ด้านล่างสุดของแถบสรุปจนมิด 100%
  * *วิธีแก้:* ใช้ CSS Selector `body:has(.mobile-bottom-nav) .sticky-summary-bar` เพื่อยกตัวแถบสรุปขึ้น `62px + Safe Area` และเปลี่ยนเลย์เอาต์เป็นแบบ Split Horizontal Dock วางปุ่มถัดไปไว้ฝั่งขวาที่มีขนาดสัมผัส 44px ให้เห็นได้ชัดเจนตลอดเวลา พร้อมเพิ่ม `padding-bottom` ในพาเนลขั้นตอนที่ 3 ป้องกันการบดบังเนื้อหาท้ายหน้า
