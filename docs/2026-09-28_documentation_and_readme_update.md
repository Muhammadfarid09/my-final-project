## 2. ระบบเป็นอย่างไร (How the System Works)

### โครงสร้างการเชื่อมโยงเอกสาร (Documentation Architecture):
```text
ts-pattani/
├── README.md                      <-- เอกสารหลักหน้าบ้านสำหรับ GitHub (ภาพรวม, ติดตั้ง, บัญชีทดสอบ)
├── GEMINI.md                      <-- กฎควบคุมการทำงานของ AI Assistant และมาตรฐานการบันทึกงาน
└── docs/
    ├── CHANGELOG.md               <-- ประวัติการพัฒนาและปรับปรุงระบบภาพรวมทั้งหมด (Master Changelog)
    ├── USER_SCOPE_AUDIT_RESULT.md <-- ตารางเทียบขอบเขต 1.3 กับโค้ดจริง (Traceability Matrix)
    ├── 2026-09-25_...md           <-- บันทึกรายวัน: แก้ไขบัคเร่งด่วนและหน้าโปรไฟล์
    ├── 2026-09-26_...md           <-- บันทึกรายวัน: รับคืนอุปกรณ์, Walk-in, Matrix, คิดราคาตามวัน
    └── 2026-09-28_...md           <-- บันทึกรายวัน: ปรับปรุงเอกสารและจัดทำ README.md
```

* **README.md:** ทำหน้าที่เป็น First Impression ของโครงงาน เมื่ออาจารย์หรือคณะกรรมการเปิดเข้ามาดูผ่าน GitHub จะเห็นหน้าตา ภาพรวม วิธีติดตั้ง และบัญชีทดสอบทันที
* **CHANGELOG.md & Daily Logs:** ทำหน้าที่เป็นหลักฐานเชิงประจักษ์ (Audit Trail) ยืนยันว่าระบบถูกพัฒนาขึ้นอย่างเป็นขั้นตอนตามหลักวิศวกรรมซอฟต์แวร์
