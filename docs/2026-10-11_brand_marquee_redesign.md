# รายงานการปรับปรุงและแก้ไข Brand Banner Marquee Slider (Premium Redesign & Bug Fix)

**วันที่:** 11 ตุลาคม 2026  
**ระบบ:** T.S. Pattani Badminton - Landing Page (`index.php`)  
**เป้าหมาย:** แก้ไขปัญหาไอคอนรูปภาพไม่แสดงผล (Broken Image Bug) ในชุดแบรนด์พันธมิตร และปรับขนาดการ์ดแบนเนอร์ให้มีขนาดใหญ่ขึ้น ชัดเจน พรีเมียม ตามหลัก HCI และมาตรฐาน Premium Black & Gold Theme

## 1. สิ่งที่ได้ดำเนินการ (What Was Done)

### 1.1 การแก้ไขบั๊กไอคอนรูปภาพเสีย (Fix Broken Image Bug)
- **สาเหตุ:** การตั้งค่าระหว่างชุดลูปที่ 1 และชุดลูปที่ 2 ใน `index.php` ไม่สอดคล้องกัน (Loop 1 และ Loop 2 มีการเรียกไฟล์ภาพไม่ตรงกัน โดยมีการอ้างอิง Ashaway แทนที่จะเป็น ASICS ซึ่งผู้ใช้ต้องการใช้งาน หรือพบปัญหาการโหลดรูปภาพ)
- **การดำเนินการ:**
  1. สร้างไฟล์โลโก้ความละเอียดสูงทางการสำหรับ **ASICS** (`assets/img/brands/asics.png` สัดส่วน 1024x285 พิกเซล คมชัด สไตล์เวกเตอร์)
  2. ปรับการเรียกใช้งานใน `index.php` ให้ทั้งสองลูป (Loop 1 และ Loop 2) สอดคล้องกัน 100%:
     - แบรนด์ 7 รายการ: **YONEX**, **VICTOR**, **LI-NING**, **MIZUNO**, **DUNLOP**, **ASICS**, **T.S. PRO SHOP**
  3. เพิ่มแอตทริบิวต์ `loading="lazy"` ให้กับรูปภาพแบนเนอร์ทั้ง 14 รายการเพื่อลดภาระการโหลดและเพิ่มความเร็วหน้าเว็บตามหลัก HCI

### 1.2 การออกแบบและขยายขนาดการ์ดแบนเนอร์ใหม่ (Upscale & Premium Redesign)
- **ปัญหาเดิม:** การ์ดเดิมมีความสูงเพียง 42px ส่งผลให้โลโก้ที่มีอัตราส่วนแนวนอนกว้าง (3.6:1) มีความสูงเพียงประมาณ 34px และกว้างเพียง 140px ตัวหนังสือของแบรนด์จึงดูเล็กและไม่โดดเด่นบนหน้าจอ Desktop
- **การปรับปรุง CSS ใน `assets/css/style.css`:**
  - เพิ่มความสูงของการ์ด `.brand-banner-card` จาก **42px เป็น 60px** (ขยายพื้นที่มองเห็นขึ้นกว่า 42%)
  - ปรับความหนาและสีของขอบเป็น `1.5px solid var(--border-color)`
  - ปรับความโค้งมนของขอบเป็น `border-radius: 12px` (และภาพภายใน `border-radius: 8px` พร้อม padding 4px) ให้ความรู้สึกเป็นตลับการ์ดหรูหรา
  - เพิ่มมิติความลึก (Depth Shadow): `box-shadow: 0 4px 16px rgba(0, 0, 0, 0.45)`
  - ปรับแต่ง Interactive Hover Effect:
    - ยกการ์ดลอยขึ้น `transform: translateY(-4px)`
    - เปล่งประกายแสงสีทองหรูหรา `box-shadow: 0 8px 24px rgba(255, 185, 29, 0.3)`
    - เปลี่ยนสีขอบเป็น `border-color: var(--color-gold)`
    - ซูมภาพข้างในเล็กน้อยอย่างนุ่มนวล `transform: scale(1.03)`
  - เพิ่มระยะห่างระหว่างการ์ดในลูป `.marquee-track` จาก **28px เป็น 32px**
  - ปรับความสูงของเซกชัน `.brand-marquee-section` จาก **28px 0 เป็น 38px 0**
  - ปรับขนาดและระยะของหัวข้อเซกชัน `.marquee-heading` เป็น **14px** พร้อมระยะห่างตัวอักษร **letter-spacing: 2px**
- **การปรับปรุง Responsive บนหน้าจอมือถือ ใน `assets/css/responsive-mobile.css`:**
  - ปรับขนาดความสูงการ์ดบนมือถือจาก **34px เป็น 46px** (พร้อม `border-radius: 8px`)
  - ปรับระยะ Gap บนมือถือเป็น `20px` และ Padding เซกชันเป็น `24px 0`

## 3. การตรวจสอบความสอดคล้องกับกฎระเบียบ (Compliance Verification)

1. **DRY Principle:** ใช้คลาส CSS กลาง `.brand-banner-card` และ `.brand-banner-img` ควบคุมสไตล์ทั้ง 14 การ์ดโดยไม่มีการเขียนสไตล์ซ้ำซ้อน
2. **Separation of Concerns:** 
   - ไม่มี Inline Style (`style="..."`) ใน `index.php`
   - ไม่มีบล็อก `<style>` แทรกกลางไฟล์
   - ไม่มีคำสั่ง `!important` ในไฟล์ CSS ทั้งหมด
3. **Safety First & Blast Radius:** ไม่กระทบกับเซกชันอื่น ไม่มีการเปลี่ยนคลาสพื้นฐานของระบบ
4. **HCI Standards:** ขยายขนาดให้มองเห็นชัดเจนตามหลัก Visual Ergonomics, Hover Micro-interactions ให้การตอบสนองที่ชัดเจนและนุ่มนวล
