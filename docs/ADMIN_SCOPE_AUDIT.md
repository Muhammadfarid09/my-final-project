# ADMIN_SCOPE_AUDIT.md

# ตรวจสอบการทำงานของผู้ดูแลระบบ (Admin)
## อ้างอิงหัวข้อ 1.3 ขอบเขตการทำงานของระบบ

## วัตถุประสงค์
ตรวจสอบ Source Code ของโปรเจกต์ว่า **ระบบผู้ดูแลระบบ (Admin) ทำงานครบและตรงตามขอบเขตหัวข้อ 1.3 ของรายงานหรือไม่**

> ต้องตรวจจาก Code, Database, PHP, JavaScript/AJAX, SQL, UI และ Business Logic จริงเท่านั้น  
> ห้ามเดา และห้ามถือว่ามีฟังก์ชันเพียงเพราะพบเมนูหรือปุ่ม

## กติกา
1. อ่านโครงสร้างโปรเจกต์ทั้งหมดก่อนตรวจ
2. ตรวจ Frontend + Backend + Database + JS/AJAX
3. ทุก Requirement ต้องมีหลักฐานจากไฟล์/ฟังก์ชัน/SQL/Table ที่เกี่ยวข้อง
4. ห้ามแก้ Source Code, Database, CSS, HTML, PHP, JS หรือ Business Logic
5. สร้างเฉพาะ `ADMIN_SCOPE_AUDIT_RESULT.md`
6. ถ้าหาไม่พบให้เขียน `Not Found` ห้ามเดา
7. UI มีแต่ Logic/DB ไม่มี = `Partial`
8. มี Logic แต่ทำงานไม่ครบ/ผิด = `Partial`
9. ระบุ File + Function/Method + Table/SQL/Route เมื่อค้นพบ

## สถานะ
| Status | ความหมาย |
|---|---|
| Implemented | ทำงานจริงและตรง Requirement |
| Partial | มีบางส่วน/ยังไม่ครบ/มีปัญหา |
| Missing | Requirement ระบุไว้แต่ไม่พบการทำงานจริง |
| Not Found | ค้นหาแล้วไม่พบหลักฐานเพียงพอ |
| N/A | ไม่เกี่ยวข้องกับ Admin |

# 1.3.6 ระบบการจองสนามและคำนวณยอด

### ตรวจการทำงาน
- [ ] Admin ดูรายการจองได้
- [ ] คำนวณค่าสนาม
- [ ] คำนวณค่าเช่า
- [ ] คำนวณค่าสินค้า
- [ ] รวมยอดถูกต้อง
- [ ] ป้องกันการจองซ้อน
- [ ] มี Atomic Locking หรือกลไกเทียบเท่า
- [ ] Booking ถูก Lock เป็น `รอตรวจสอบ`
- [ ] ไม่ส่งสลิปภายใน 15 นาทีแล้ว Booking ถูกยกเลิก
- [ ] Lock ถูกปลดหลัง Timeout
- [ ] สนามกลับมาจองได้หลัง Timeout

### ตรวจ Flow
`เลือกสนาม → ตรวจว่าง → Lock → สร้าง Booking → ชำระเงิน → Upload Slip → Admin ตรวจ → Confirm`

และ

`ไม่มี Slip 15 นาที → Cancel → Unlock → สนามว่าง`

# 7. หลักการสรุป

ต้องตอบให้ได้ว่า:

> **ระบบผู้ดูแลระบบที่เขียนอยู่ในปัจจุบัน ทำงานตรงตามขอบเขตหัวข้อ 1.3 ของรายงานจริงแค่ไหน?**

ให้ทำ Traceability:

`1.3 Requirement → UI/Page → PHP/JS → Database → Business Logic → ผลลัพธ์`

ถ้า Requirement มีในรายงานแต่ไม่มี Code รองรับ ให้ระบุ Gap อย่างชัดเจน

ถ้า Code มีฟังก์ชันเกินจากรายงาน ให้แยกไว้ใน `สิ่งที่พบเพิ่มเติม` และอย่านับเป็น Requirement ของโครงงานโดยอัตโนมัติ
