# รายงานการปรับปรุงการคำนวณช่วงเวลาสนามแบบ Dynamic จากฐานข้อมูลจริง

**โครงการ:** ระบบบริหารจัดการสนามแบดมินตัน T.S. Pattani  
**ไฟล์ที่ดำเนินการ:** `actions/get_court_matrix.php`

## 1. ทำอะไรบ้าง (What Was Done)
* **แก้ไขไฟล์:** [actions/get_court_matrix.php](file:///c:/xampp/htdocs/ts-pattani/actions/get_court_matrix.php)
  - ยกเลิกการฮาร์ดโค้ดลูปสร้าง Time Slots เดิม (`for ($h = 9; $h < 23; $h++)`) ซึ่งจำกัดเวลาเริ่มไว้ที่ 09:00 น. เท่านั้น
  - พัฒนาระบบคำนวณช่วงเวลาแบบ **Dynamic** โดยดึงเวลาเปิดที่เช้าที่สุด (`court_open_time`) และเวลาปิดที่ดึกที่สุด (`court_close_time`) จากข้อมูลสนามทั้งหมดในตาราง `Court` ในฐานข้อมูลจริง
  - ปรับค่าเวลาเปิด-ปิดสำรอง (Fallback) ให้สอดคล้องกับค่า Dynamic ที่คำนวณได้จริง

---

## 2. ระบบเป็นอย่างไร (How the System Works)
* **Logic การคำนวณช่วงเวลา (Dynamic Time Slot Generation):**
  1. ดึงข้อมูลสนามทั้งหมดจากฐานข้อมูล (`Court`) ซึ่งมีค่า `court_open_time` และ `court_close_time` ของแต่ละสนาม
  2. สกัดชั่วโมงเปิดที่เช้าที่สุด (`$min_open_hour`) และชั่วโมงปิดที่ดึกที่สุด (`$max_close_hour`)
  3. วนลูปสร้าง Time Slots ตั้งแต่ `$min_open_hour` ถึง `$max_close_hour`
  4. ผลลัพธ์: หากแอดมินตั้งเวลาเป็น 08:00 - 23:00 น. ระบบจะสร้าง Time Slots ตั้งแต่ `08:00 - 09:00` ไปจนถึง `22:00 - 23:00` อัตโนมัติ
  5. รองรับการเปลี่ยนแปลงในอนาคต 100% หากแอดมินเปลี่ยนเวลาเปิด-ปิดในหลังบ้าน หน้าบ้านของสมาชิกจะปรับเปลี่ยนตามทันทีโดยไม่ต้องแก้ไขโค้ด

## 3. การใช้งานอย่างไร (How to Use / Test)
1. เข้าสู่ระบบฝั่งสมาชิกแล้วไปที่หน้าจองสนาม: `http://localhost/ts-pattani/booking.php`
2. เลือกวันที่ในขั้นตอนที่ 1 แล้วกดเข้าสู่ **ขั้นตอนที่ 2 (เลือกเวลาเริ่มต้น)**
3. ตรวจสอบการ์ดเวลา: จะพบการ์ด **08:00 น. เปิดให้บริการ** ปรากฏขึ้นมาเป็นใบแรกทันที และใบสุดท้ายคือ **22:00 น. เปิดให้บริการ**
4. เมื่อกดเลือก 08:00 น. และเข้าสู่ **ขั้นตอนที่ 3 (เลือกสนาม)**:
   - สนามทั้ง 10 คอร์ทจะแสดงสถานะ **● ว่าง** (สีเขียว) สามารถคลิกเลือกเพื่อทำการจองได้ตามปกติ
   - ไม่มีปัญหาขึ้นปิดปรับปรุงหรือปิดบริการอีกต่อไป

## 4. ปัญหาที่เจอหรือแก้อะไรบ้าง (Issues Encountered & Resolved)
* **สาเหตุเดิม:** มีการเขียน Hardcode `$h = 9` ทำให้ระบบไม่มีสล็อต 08:00 น. แม้แอดมินจะบันทึกเวลาเปิดเป็น 08:00 น. ในฐานข้อมูลแล้ว และสล็อตที่เวลาไม่ตรงจะถูกมองว่านอกเวลาทำการ (`status = closed`) จน JavaScript นำไปแสดงผลเป็นการ์ด "ปิดบริการ/ปิดปรับปรุง"
* **การแก้ไข:** เปลี่ยนมาคำนวณแบบ Dynamic ตามข้อมูลในตาราง `Court` โดยตรง ทำให้ข้อมูลหน้าบ้านและหลังบ้านซิงค์ตรงกัน 100%
