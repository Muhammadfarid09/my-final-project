  - สร้างหน้า UI แอดมิน [admin/equipment_returns.php](file:///c:/xampp/htdocs/ts-pattani/admin/equipment_returns.php): แสดงรายการเช่าที่ต้องตรวจรับคืน, สถิติอุปกรณ์ที่กำลังเช่า, รายการคืนช้า (Overdue), ยอดค่าปรับสะสม และโมดอลตรวจรับคืน
  - สร้างคอนโทรลเลอร์ [admin/actions/equipment_return_db.php](file:///c:/xampp/htdocs/ts-pattani/admin/actions/equipment_return_db.php): จัดการคืนสต็อกสินค้าเมื่อสภาพปกติ, ส่งเข้าคิวซ่อม `Equipment_repair` อัตโนมัติเมื่ออุปกรณ์ชำรุด, ตัดจำหน่ายเมื่อสูญหาย และบันทึกรายรับค่าปรับเข้าตาราง `Revenue`
  - เพิ่มเมนู "ตรวจรับคืนอุปกรณ์" ลงใน [admin/includes/sidebar.php](file:///c:/xampp/htdocs/ts-pattani/admin/includes/sidebar.php)
* **2. พัฒนาระบบยกเลิกการจองฝั่งสมาชิก (Member Cancellation Flow):**

  - สร้างคอนโทรลเลอร์ [actions/cancel_booking_db.php](file:///c:/xampp/htdocs/ts-pattani/actions/cancel_booking_db.php): คืนสต็อกอุปกรณ์เช่ากลับเข้าสู่ระบบ, อัปเดตสถานะการจองใน `Booking` เป็น `'ยกเลิก'`, และบันทึกคำขอลงตาราง `Cancellation` สถานะ `'รอดำเนินการ'` เพื่อให้แอดมินพิจารณาคืนเงิน/พอยท์ใน [admin/cancellations.php](file:///c:/xampp/htdocs/ts-pattani/admin/cancellations.php)
* **3. พัฒนาระบบเปิดสนาม Walk-in / จองหน้าเคาน์เตอร์ผ่าน POS (Walk-in Court Booking & POS Receipt):**
  - ปรับฐานข้อมูลตาราง `Booking`: ให้คอลัมน์ `member_id` สามารถเป็น `NULL` ได้สำหรับลูกค้ารองรับ Walk-in ทั่วไป
  - อัปเดตหน้า [admin/pos.php](file:///c:/xampp/htdocs/ts-pattani/admin/pos.php): เพิ่มแท็บ **"เปิดสนาม Walk-in"** แสดงการ์ดสนามทุกคอร์ท, มีโมดอลเลือกวัน เวลาเริ่มต้น จำนวนชั่วโมง และเบอร์โทรสมาชิก (หากมี) เพื่อคำนวณราคาและเพิ่มเข้าตะกร้า POS ร่วมกับสินค้า/อุปกรณ์เช่าได้ทันที
  - อัปเดต [admin/actions/pos_checkout_db.php](file:///c:/xampp/htdocs/ts-pattani/admin/actions/pos_checkout_db.php): รองรับการสร้าง `Booking` สถานะ `'จองแล้ว'` ทันที, บันทึกการเช่าอุปกรณ์ลง `Rental`, ตัดสต็อกสินค้า, บันทึกรายรับแยกหมวดหมู่ใน `Revenue` และแจกพอยท์กรณีลูกค้าเป็นสมาชิก
  - อัปเดต [admin/receipt.php](file:///c:/xampp/htdocs/ts-pattani/admin/receipt.php): ปรับปรุงระบบพิมพ์ใบเสร็จขนาด 80mm ให้รองรับการแสดงรายละเอียดค่าเปิดสนาม Walk-in ร่วมกับสินค้าที่ซื้อ/เช่าหน้าร้าน
  - อัปเดต [assets/js/admin.js](file:///c:/xampp/htdocs/ts-pattani/assets/js/admin.js): รองรับการแสดงผลและคำนวณจำนวนชั่วโมงของสนามในตะกร้า POS และระบบ Pop-up ใบเสร็จอัตโนมัติ

## 2. ระบบเป็นอย่างไร (How the System Works)
* **โฟลว์การตรวจรับคืนและคิดค่าปรับ (Return & Fine Mechanism):**
  - สมาชิกเช่าอุปกรณ์คู่กับการจองสนาม -> ระบบบันทึกลง `Rental` สถานะ `'กำลังเช่า'`
  - เมื่อถึงเวลานำอุปกรณ์มาคืน แอดมินเปิดหน้า [admin/equipment_returns.php](file:///c:/xampp/htdocs/ts-pattani/admin/equipment_returns.php)
  - ระบบจะคำนวณเวลาคืนจริงเทียบกับกำหนดคืน (`rental_return_time`) หากเกินเวลา ระบบจะแจ้งเตือนจำนวนชั่วโมงที่เกินและแนะนำค่าปรับคืนช้าให้อัตโนมัติ
  - หากอุปกรณ์ **ชำรุด**: ระบบไม่คืนสต็อก แต่จะสร้างบันทึกส่งซ่อมลงตาราง `Equipment_repair` สถานะ 'กำลังซ่อม' ให้อัตโนมัติ
  - หากอุปกรณ์ **สูญหาย**: ระบบจะคิดค่าชดใช้เท่ากับราคาอุปกรณ์ และตัดออกจากระบบ
  - ค่าปรับทั้งหมดจะถูกนำไปลงบันทึกในตาราง `Revenue` หมวดหมู่อุปกรณ์เช่าหน้าร้าน
* **โฟลว์การยกเลิกการจองฝั่งสมาชิก (Cancellation Workflow):**
  - สมาชิกตรวจสอบประวัติการจอง -> หากยังไม่เริ่มเวลาเตะ จะมีปุ่ม "ขอยกเลิก"
  - สมาชิกกดยกเลิกและระบุเหตุผล -> ระบบคืนสต็อกอุปกรณ์เช่าทันทีเพื่อไม่ให้เสียโอกาสทางธุรกิจ -> บันทึกคำขอเข้าสู่ตาราง `Cancellation`
  - แอดมินสามารถเข้าดูที่หน้า [admin/cancellations.php](file:///c:/xampp/htdocs/ts-pattani/admin/cancellations.php) เพื่อพิจารณาคืนเงินหรือคืนพอยท์ตามสัดส่วนเวลา (100%, 70%, 50%)
* **โฟลว์เปิดสนาม Walk-in หน้าร้าน (POS Court Booking Workflow):**
  - แอดมินอยู่ที่หน้าจอ POS -> เลือกแท็บ "เปิดสนาม Walk-in" -> กดเลือกคอร์ทที่ลูกค้าต้องการ -> กำหนดเวลาและจำนวนชั่วโมง
  - ระบบจะรวมยอดค่าสนามเข้าไปในตะกร้า POS ร่วมกับน้ำดื่มหรือไม้เช่าได้ในบิลเดียว
  - รับเงินสด (มีระบบคำนวณเงินทอน) หรือสแกน QR Code
  - กดยืนยัน -> ระบบสร้าง `Booking` สถานะ 'จองแล้ว' อัตโนมัติ -> ตัดสต็อกสินค้า -> บันทึกรายรับลง `Revenue` -> เด้ง Popup พิมพ์ใบเสร็จสลิป 80mm ให้ลูกค้าทันที

## 3. การใช้งานอย่างไร (How to Use / Test)
* **1. การทดสอบตรวจรับคืนอุปกรณ์ (ฝั่ง Admin):**
  - เข้าเมนู **"ตรวจรับคืนอุปกรณ์"** (`admin/equipment_returns.php`)
  - ตรวจสอบรายการอุปกรณ์ที่ลูกค้าเช่าอยู่
  - คลิกปุ่ม **"ตรวจรับคืน"** บนรายการที่ต้องการ
  - ทดสอบเลือกสภาพ: "ปกติ" หรือ "ชำรุด" (กรอกสาเหตุ เช่น เอ็นขาด) หรือ "สูญหาย"
  - ตรวจสอบการคิดค่าปรับ -> กดยืนยันการรับคืน
  - ผลลัพธ์: สต็อกจะถูกคืน (กรณีปกติ) หรือส่งเข้าคิวซ่อม (กรณีชำรุด) และค่าปรับจะบันทึกลงรายรับ
* **2. การทดสอบยกเลิกการจอง (ฝั่ง Member):**
  - สมาชิกเข้าสู่ระบบและไปที่ **"ประวัติการจอง"** (`booking_history.php`)
  - ในรายการจองที่ยังไม่ถึงเวลา จะมีปุ่มสีแดง **"ขอยกเลิก"**
  - คลิกปุ่ม -> ระบุเหตุผลในหน้าต่าง Pop-up -> กดยืนยัน
  - ผลลัพธ์: สถานะเปลี่ยนเป็น "ยกเลิก" ทันที และสต็อกอุปกรณ์เช่าจะถูกคืนกลับเข้าระบบ
  - ฝั่ง Admin สามารถไปที่เมนู **"ระบบพิจารณายกเลิก"** (`admin/cancellations.php`) เพื่อดูคำขอและกดยืนยันคืนเงิน/คืนพอยท์
* **3. การทดสอบเปิดสนาม Walk-in หน้าร้าน (ฝั่ง Admin POS):**
  - ไปที่เมนู **"ขายหน้าร้าน (POS)"** (`admin/pos.php`)
  - คลิกแท็บ **"เปิดสนาม Walk-in"** -> คลิกเลือกสนาม เช่น `courts 1`
  - เลือกระยะเวลา (เช่น 2 ชั่วโมง) และระบุเบอร์โทรลูกค้า (ถ้ามี) -> กด **"เพิ่มสนามลงบิล POS"**
  - สามารถสลับไปแท็บ "น้ำดื่ม/ลูกแบด" เพื่อเพิ่มสินค้าเข้าบิลเดียวกันได้
  - เลือกวิธีชำระเงิน "เงินสด" -> ใส่จำนวนเงินที่รับมา -> กด **"ยืนยันการชำระเงิน & ออกใบเสร็จ"**
  - ผลลัพธ์: ระบบจะบันทึกการจองและตัดสต็อกสินค้า พร้อมเปิดหน้าต่าง Pop-up ใบเสร็จ 80mm สำหรับสั่งพิมพ์ได้ทันที

## 4. ปัญหาที่เจอหรือแก้อะไรบ้าง (Issues Encountered & Resolved)
* **ปัญหาที่ 1: ตาราง Booking ไม่อนุญาตให้ `member_id` เป็น NULL**
  - *สาเหตุ:* โครงสร้างเดิมบังคับ `member_id NOT NULL` ทำให้การเปิดสนาม Walk-in สำหรับลูกค้าขาจรที่ไม่มีบัญชีสมาชิกทำไม่ได้
  - *การแก้ไข:* รันคำสั่ง `ALTER TABLE Booking MODIFY COLUMN member_id INT(11) NULL;` และอัปเดตไฟล์ `setup.php` ให้รองรับลูกค้าทั่วไป
* **ปัญหาที่ 2: ตาราง Rental ขาดฟิลด์บันทึกค่าปรับและเวลาคืนจริง**
  - *สาเหตุ:* ตาราง `Rental` มีเพียงฟิลด์สถานะ ไม่มีฟิลด์สำหรับเก็บจำนวนเงินค่าปรับ เหตุผล และเวลาที่นำมาคืนจริง
  - *การแก้ไข:* เพิ่มคอลัมน์ `rental_fine`, `rental_fine_reason`, `rental_actual_return` และปรับค่า ENUM ให้รองรับ 'ชำรุด' และ 'สูญหาย'
* **ปัญหาที่ 3: สมาชิกไม่มีช่องทางกดยกเลิกการจองด้วยตนเอง**
  - *สาเหตุ:* มีระบบพิจารณายกเลิกฝั่งแอดมินอยู่แล้ว แต่ฝั่งสมาชิกไม่มีปุ่มและไม่มี Action ในการส่งคำขอยกเลิก
  - *การแก้ไข:* สร้าง Action `cancel_booking_db.php` และเพิ่ม Modal ขอยกเลิกในหน้าประวัติการจอง พร้อมคืนสต็อกอุปกรณ์เช่าทันที
* **ปัญหาที่ 4: ใบเสร็จ POS รองรับเฉพาะการขายสินค้า ไม่รองรับบิลสนาม**
  - *สาเหตุ:* หน้า `admin/receipt.php` ผูกข้อมูลเฉพาะกับตาราง `Pos_sale`
  - *การแก้ไข:* ปรับให้รองรับทั้ง `pos_id` และ `booking_id` เพื่อพิมพ์ใบเสร็จรวมทั้งค่าสนามและสินค้าได้ในบิลเดียว
