## 1. ทำอะไรบ้าง (What Was Done)
* **ปรับปรุงหน้าสมัครสมาชิก (`register.php`):**
  - ออกแบบ Card Form กึ่งกลางหน้าจอ โทนสีหลักตามธีม (`var(--brand-primary)` / `#007bff`)
  - เพิ่มหัวข้อหลัก "สมัครสมาชิก" (ตัวหนา สีฟ้าเด่นชัด) และชื่อสนาม "T.S. Pattani Badminton"
  - จัดระเบียบรายการฟิลด์ข้อมูลพร้อมไอคอนนำหน้าและ Label ตัวหนาทุกฟิลด์:
    1. **ชื่อ - นามสกุล *:** ไอคอนรูปคน (`fa-user`), placeholder: "กรอกชื่อ-นามสกุล"
    2. **เบอร์โทรศัพท์ (ใช้เข้าสู่ระบบ) *:** ไอคอนโทรศัพท์ (`fa-phone`), `inputmode="tel"`, placeholder: "08X-XXX-XXXX", บังคับตัวเลข 10 หลักขึ้นต้นด้วย 0
    3. **เพศ:** ไอคอนเพศ (`fa-venus-mars`), `<select name="member_gender">` ตัวเลือก: ชาย, หญิง, อื่นๆ / ไม่ระบุ
    4. **อายุ (ปี):** ไอคอนปฏิทิน (`fa-calendar-alt`), Number input ช่วงอายุ 5 - 100 ปี (จัดวางคู่กับช่องเพศใน Grid 2 คอลัมน์)
    5. **อาชีพ:** ปรับเป็น `<select name="member_occupation">` พร้อมไอคอนกระเป๋า (`fa-briefcase`) โดยจัดขนาดความสูง (46px), Padding และลูกศร SVG ให้เท่ากับช่องเพศ 100%
    6. **รหัสผ่าน *:** ไอคอนแม่กุญแจ (`fa-lock`), ความยาวขั้นต่ำ 6 ตัวอักษร พร้อมปุ่มสลับเปิด/ปิดดวงตา (`fa-eye` / `fa-eye-slash`)
    7. **ยืนยันรหัสผ่านอีกครั้ง *:** ไอคอนตรวจสอบ (`fa-check-circle`) พร้อมปุ่มสลับเปิด/ปิดดวงตา และระบบแจ้งเตือนแบบเรียลไทม์ (รหัสผ่านตรงกัน / ไม่ตรงกัน)
  - เพิ่มการรักษาพารามิเตอร์ `redirect` ส่งต่ออัตโนมัติหากมาจากการจองสนาม (`booking.php`)
  - อัปเดตลิงก์ไปยังหน้าเข้าสู่ระบบ "มีบัญชีอยู่แล้วใช่ไหม? เข้าสู่ระบบที่นี่" พร้อมส่งต่อค่า `redirect`

* **พัฒนาระบบสไตล์ CSS (`assets/css/style.css` และ `assets/css/responsive-mobile.css`):**
  - เพิ่มคลาส `.auth-card-register`, `.auth-title`, `.auth-subtitle`, `.form-label`, `.text-danger`
  - สร้าง `.input-group.select-wrap select.select-control` พร้อมกำหนด Custom SVG Dropdown Arrow เพื่อความสม่ำเสมอของ UI
  - สร้าง `.form-row` จัดกริด 2 คอลัมน์ และยุบเป็น 1 คอลัมน์บนมือถือขนาดเล็ก
  - สร้าง `.btn-toggle-password`, `.password-match-hint`, `.btn-auth-full`
  - ปฏิบัติตามกฎเหล็ก: **ไม่มี Inline Styles**, **ไม่มีบล็อก `<style>` กลางไฟล์**, **ไม่มี `!important`**

* **พัฒนาระบบตรวจสอบฝั่งผู้ใช้ (`assets/js/member.js`):**
  - เพิ่มฟังก์ชัน `initRegisterForm()` ครอบด้วย IIFE ป้องกัน Global Scope Pollution
  - กรองเบอร์โทรศัพท์ให้อนุญาตเฉพาะตัวเลขและตัดความยาวไม่เกิน 10 หลัก
  - ฟังก์ชันตรวจสอบรหัสผ่านคู่เทียบแบบ Real-time (`checkPasswordMatch`)
  - ฟังก์ชันสลับแสดง/ซ่อนรหัสผ่านสำหรับทั้งสองช่องอย่างอิสระ
  - กลไกป้องกันการกดยืนยันซ้ำ (Double Submission Prevention) พร้อมเปลี่ยนปุ่มเป็น Spinner และสถานะ Disabled

* **ปรับปรุงการตรวจสอบและการบันทึกฝั่งเซิร์ฟเวอร์ (`actions/register_db.php`):**
  - ตรวจสอบรูปแบบเบอร์โทรศัพท์ด้วย Regex `/^0[0-9]{9}$/`
  - ตรวจสอบความถูกต้องของอายุ (5 - 100 ปี) และความยาวรหัสผ่าน (>= 6 ตัวอักษร)
  - ตรวจสอบความซ้ำซ้อนของเบอร์โทรศัพท์ในตาราง `Member` ด้วย Prepared Statements
  - บันทึกรหัสผ่านด้วย `password_hash($member_password, PASSWORD_DEFAULT)`
  - รองรับ Database Transaction ครอบคลุมการสร้างบัญชีในตาราง `Member` และเปิดบัญชีคะแนนสะสมเริ่มต้นในตาราง `Point`
  - ส่งต่อผู้ใช้ไปยัง `login.php` พร้อม Flash Message แจ้งเตือนความสำเร็จและค่า `redirect`

## 2. ระบบเป็นอย่างไร (How the System Works)
```
+-----------------------------------------------------------------------------------+
| 1. ผู้ใช้เข้าหน้า register.php (พร้อม ?redirect=booking.php ถ้ามาจากการจอง)       |
+-----------------------------------------------------------------------------------+
                                         |
                                         v
+-----------------------------------------------------------------------------------+
| 2. ฝั่ง Client (member.js):                                                       |
|    - กรองเบอร์โทรเฉพาะตัวเลข 10 หลักอัตโนมัติ                                     |
|    - สลับดูรหัสผ่านได้ผ่านปุ่มลูกตา                                               |
|    - ตรวจสอบความตรงกันของรหัสผ่านแบบ Real-time (เขียว/แดง)                        |
|    - เมื่อกดส่งฟอร์ม ตรวจสอบความถูกต้องทั้งหมด + ป้องกัน Double Submit             |
+-----------------------------------------------------------------------------------+
                                         | (POST ส่งข้อมูล)
                                         v
+-----------------------------------------------------------------------------------+
| 3. ฝั่ง Backend (actions/register_db.php):                                        |
|    - ตรวจสอบ CSRF/Method POST                                                     |
|    - Sanitization & Validation (Phone regex, Age range, Password match)           |
|    - ตรวจสอบเบอร์โทรซ้ำในตาราง Member (Prepared Statement)                         |
|    - เริ่ม DB Transaction:                                                        |
|        a) INSERT ข้อมูลลงตาราง Member                                             |
|        b) INSERT คะแนนเริ่มต้น 0 แต้ม (Bronze) ลงตาราง Point                     |
|    - Commit Transaction                                                           |
+-----------------------------------------------------------------------------------+
                                         |
                                         v
+-----------------------------------------------------------------------------------+
| 4. เปลี่ยนเส้นทางไปยัง login.php?registered=1&phone=08XXXXXXXX&redirect=booking.php|
|    (แจ้งเตือนสมัครสำเร็จ และพาไปหน้าเข้าสู่ระบบอัตโนมัติ)                         |
+-----------------------------------------------------------------------------------+
```

## 3. การใช้งานอย่างไร (How to Use / Test)
1. **เข้าสู่หน้าสมัครสมาชิก:**
   - เข้าทาง URL: `http://localhost/ts-pattani/register.php`
   - หรือหากมาจากขั้นตอนการจองสนาม ระบบจะพามาที่ `register.php?redirect=booking.php`
2. **ทดสอบระบบตรวจสอบความถูกต้อง (Client & Server Validation):**
   - ลองกดปุ่ม "ยืนยันการสมัครสมาชิก" ทันที -> ระบบจะแจ้งเตือนให้กรอกชื่อ-นามสกุล
   - ลองกรอกเบอร์โทรศัพท์ผิด เช่น ไม่ครบ 10 หลัก หรือมีตัวอักษร -> ระบบจะตัดตัวอักษรออกและแจ้งเตือนรูปแบบเบอร์
   - ลองกรอกรหัสผ่านช่องแรกและช่องยืนยัน -> สังเกตข้อความใต้ช่องยืนยันรหัสผ่านจะเปลี่ยนเป็นสีเขียว "รหัสผ่านตรงกัน" หรือสีแดง "รหัสผ่านไม่ตรงกัน" ทันที
   - กดปุ่มรูปลูกตาด้านขวาของช่องรหัสผ่าน -> รหัสผ่านจะสลับระหว่างการซ่อนและแสดงผล
   - ตรวจสอบช่อง "เพศ" และ "อาชีพ" -> ทั้งสองช่องเป็น Dropdown ที่มีความสูง 46px ขอบมน และไอคอนนำหน้าเสมอกัน 100%
3. **ทดสอบการสมัครสมาชิกสำเร็จ:**
   - กรอกข้อมูลที่ถูกต้องครบถ้วน
   - กดปุ่ม "ยืนยันการสมัครสมาชิก" -> ปุ่มจะเปลี่ยนเป็น "กำลังบันทึกข้อมูล..." พร้อมไอคอนหมุน ป้องกันการกดซ้ำ
   - ระบบจะพาไปยังหน้า `login.php` พร้อมข้อความแจ้งเตือน "สมัครสมาชิกสำเร็จ กรุณาเข้าสู่ระบบด้วยเบอร์โทรศัพท์ของคุณ"

## 4. ปัญหาที่เจอหรือแก้อะไรบ้าง (Issues Encountered & Resolved)
1. **Dropdown อาชีพเดิมเป็น Text Input และไม่สอดคล้องกับช่องเพศ:**
   - *สาเหตุ:* โค้ดเดิมใช้ `<input type="text">` ทำให้ความกว้าง รูปแบบการกรอก และการแสดงผลไม่ตรงกับช่องเพศ (`<select>`)
   - *วิธีแก้:* เปลี่ยนเป็น `<select name="member_occupation">` พร้อมใช้คลาส `.select-control` และกำหนด CSS Custom SVG ลูกศร Dropdown ให้มี Padding (ขวา 40px, ซ้าย 42px) ความสูง 46px และ Border เท่ากันทุกมิติ
2. **ปัญหาการส่งฟอร์มซ้ำ (Double Submission):**
   - *สาเหตุ:* ผู้ใช้อาจกดยืนยันหลายครั้งระหว่างที่เครือข่ายหน่วง ทำให้เกิด Request ซ้ำไปยังฐานข้อมูล
   - *วิธีแก้:* เพิ่มตัวแปรสถานะ `isSubmitting` ใน `member.js` พร้อม Disable ปุ่มและแสดง Loading Spinner ทันทีที่การตรวจสอบผ่าน
3. **ความต่อเนื่องของ Session การจองสนาม (Guest Booking Flow):**
   - *สาเหตุ:* ผู้ใช้ที่ยังไม่ได้เข้าสู่ระบบและเริ่มจองสนาม เมื่อมากดสมัครสมาชิก ค่าหน้าปลายทางอาจสูญหาย
   - *วิธีแก้:* ส่งต่อพารามิเตอร์ `?redirect=...` ผ่าน Hidden Input และส่งต่อไปยัง `login.php` อย่างต่อเนื่อง
